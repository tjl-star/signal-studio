# 新版视频运营数据看板

独立于历史 `dashboard-demo` 与 V1 基线。页面只读取 `data/` 内由桌面真实文件复制的快照，不使用 mock 数据。

下载或克隆仓库后运行：

```powershell
cd dashboard-v2
python -m http.server 8000
```

本机访问 `http://127.0.0.1:8000/`。

Windows 用户也可以双击 `启动看板.bat`，脚本会自动使用系统中的 Python 启动本地服务。

共享给同事时，不能分享 `localhost` 或 `127.0.0.1`，应分享本机局域网 IP（例如
`http://192.168.x.x:8000/dashboard-v2/`）或反向隧道生成的公网 HTTPS 地址。
也可以直接运行 `启动共享看板.bat`，它会绑定所有网卡并打开本机入口。

## 数据说明

仓库已包含当前看板所需的本地真实数据快照，下载后无需配置接口 Token 即可运行。
如需更新数据，请在原项目环境中重新生成快照后替换 `data/` 目录中的文件。
