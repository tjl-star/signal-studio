## 2. 重要代码文件

### `index.html`

页面结构和模块入口。当前包含：

- 左侧一级导航：大盘总览、内容榜单、搜索分析
- 顶部端口筛选：安卓、iOS、M站
- 趋势周期：近7天、近30天
- 大盘KPI、趋势图、播放行为趋势
- 热播榜单
- 搜索分析转换链路、搜索趋势、热搜榜和新老设备搜索行为

### `dashboard.js`

主要前端逻辑：

- `CLIENTS`：端口映射，当前只有 `android`、`ios`、`m`
- `state.client`：当前选中的端口，默认 `android`
- `state.period`：趋势周期，默认近30天
- `metricRows()`：读取大盘趋势并按端口筛选
- `playbackRows()`：读取播放行为趋势并按端口筛选
- `searchRows()`：读取搜索转换数据并按端口筛选
- `searchFiveRows()`：读取当前端口的“播放5分钟UV整体转化率”
- `renderSearch()`：渲染搜索分析模块

不要在前端自行把安卓、iOS、M站相加生成“全部端口”。用户已明确删除“全部”筛选，因为后台还有其他端口，三端相加不等于后台全部口径。

### `style.css`

当前冷白色成熟BI驾驶舱视觉、左侧窄栏、响应式布局、图表和表格样式。后续修改应避免改变数据逻辑。

### `real-data.json`

正式页面的主真实数据文件，包含：

- `core_dashboard`：大盘KPI、趋势、播放行为、热播榜
- `search_analysis`：搜索分析数据

### `search-analysis-data.json`

搜索分析的独立真实数据备份/回退文件。当前已与 `real-data.json` 同步补充端口字段。

### `sync_data_provider.py`

历史数据同步和整理脚本。修改前先确认输出是否会覆盖人工导出的真实文件。

### `echarts.min.js`

本地 ECharts 依赖，不要替换为 Mock 图表库。
